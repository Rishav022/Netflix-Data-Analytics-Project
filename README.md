\# Netflix Data Analytics Project



\## Overview



This project analyzes the Netflix Movies and TV Shows dataset using Python. The goal is to clean the raw dataset, perform exploratory data analysis (EDA), and generate meaningful insights through data visualization. The project also prepares the cleaned dataset for building an interactive Power BI dashboard.



\## Tech Stack



\- Python

\- NumPy

\- Pandas

\- Matplotlib

\- Jupyter Notebook

\- Power BI (Dashboard in Progress)



\## Project Workflow



1\. Data Collection

2\. Data Loading

3\. Data Cleaning

4\. Data Preprocessing

5\. Exploratory Data Analysis (EDA)

6\. Data Visualization

7\. Preparing Dataset for Dashboard Development



\## Analysis Performed



\- Distribution of Movies and TV Shows on Netflix.

\- Top 10 content-producing countries and their contribution.

\- Comparison of Movies and TV Shows across the top 10 countries.

\- Year-wise trend of content added to Netflix.

\- Month-wise analysis of content additions.

\- Distribution of Netflix content ratings.

\- Genre distribution and trend analysis over the years.

\- Identification of the most common genres on Netflix.

\- Analysis of movie duration and TV show seasons.

\- Analysis of directors with the highest number of titles.

\- Analysis of average movie duration across different categories.
